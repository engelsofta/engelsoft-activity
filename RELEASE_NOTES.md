**📈 Your lights have mood swings. We graphed them.**

Open **Charts** from the Activity side rail to compare up to eight entities using the history already recorded by Home Assistant.

### Compare entity history

- Search for entities, show or hide individual series, and remove them from their matching cards. The sidebar badge counts the selected entities.
- Compare measurements on scales grouped by unit and see switches and text states on separate state bands. A shared cursor shows the value of each entity at the same time.
- Drag a plot to move through time, zoom around the pointer with **Ctrl + mouse wheel**, or use the toolbar to change the time range and export CSV.

### Find and revisit events

- Use the chart icon in an activity row to add its entity and pin the exact event. Jump back to any saved pin. Charts keep their position when a pin moves outside the visible time range.
- Chart, favorite, and hide actions stay visible in the timeline. The overview tiles filter automations and notices.

### Upgrade

Requires Home Assistant 2026.11 or newer. Restart Home Assistant and reload the browser after updating.
