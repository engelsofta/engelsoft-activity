**The lights talked. We followed the trace.**

Engelsoft Activity now supports two Activity features introduced in **Home Assistant 2026.11**.

- **Triggered by** (*Ausgelöst durch*) filters events by linked person, automation, script, integration, or other cause. Find it under **Further filters** (*Weitere Filter*).
- **Open trace** (*Trace öffnen*) links to the exact automation or script run in the event details, even when several runs share the same context. Links are shown to administrators for runs with recorded IDs and a stored trace.

After updating, restart Home Assistant and reload the browser.
